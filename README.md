# LevelUp Lab

Kids educational portal — a frontend-only Vue 3 app for homework practice by grade, subject, and exercise.

## Stack

- Vue 3 (`<script setup>`)
- Vite
- Vue Router
- Tailwind CSS v4
- GitHub Pages

## Quick start

```bash
npm install
npm run dev
```
